# Figma 组件创建器

把你已有的产品（网页 demo、iOS 应用、Android 应用、或者已经画了一半的 Figma 设计稿），转化成一份完整的 Figma 组件库。

## 主要会做的事

### 启动准备
- 读取项目里已有的设计约束文档
- 读取你之前的设计沿用记录
- 检查目标 Figma 文件当前的状态

### 摸清源头
- 识别源头是网页、应用还是 Figma 设计稿
- 如果源头是网页或应用：从代码里抠出真实的颜色、字号、间距、圆角等基础设定
- 如果源头是 Figma 设计稿：
  - 先识别里面已经做好的组件和规则，直接登记下来不重复造
  - 再扫描那些反复出现但还没整理成规则的元素（颜色、字号、间距、圆角、相似的图层组合），列出来等你决定要不要提取
- 列出所有关键页面
- 列出已存在的可复用元素

### 字体探测
- 检测当前 Figma 实际能用到哪些字体
- 自动避开不可用的字体
- 给中英文挑最合适的搭配

### 整理清单交给你审阅
- 分层列出所有要做的内容
- 每条标明中文名称、功能说明、所有状态、所有可切换样式
- 等你确认或调整

### 得到你明确许可后开始生成
- 从基础到组合按顺序分批做
- 每批数量受限不会一次扔太多
- 每批做完自己先比对源头
- 视觉不接近源头不交付

### 每批做完暂停等你
- 让你去 Figma 里检查
- 你可以让它继续、改这批、重做这批、先停下

### 收尾
- 把这次做了什么记录到项目里
- 把发现的注意事项写进历史
- 给你一份总结报告

## 它绝对不会做的事

- 未经你同意就动手
- 一次性堆给你一大堆
- 用凭印象拍脑袋的数值
- 跳过你的验收
- 用会出问题的字体
- 如果源头是 Figma：未经你同意就动你已经画好的图层
- 如果源头是 Figma：把只出现过一两次的图层硬当成共用规则提取

## 怎么激活它

跟它说类似的话：
- 从这套代码或设计生成 Figma 组件库
- 把这个应用做成 Figma 版本
- 在 Figma 里建一套组件
- 做一套 Figma 设计规范
- 从这份 Figma 设计稿里提取组件和规则
- 整理这份 Figma 已有的组件和变量
